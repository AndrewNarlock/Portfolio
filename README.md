# Andrew Narlock Portfolio

Personal portfolio of Andrew Narlock: <https://andrewnarlock.github.io/Portfolio/>

The home page opens on 3D "digital rain" drawn with WebGL (`scripts/matrix-rain.js`), followed by a carousel of five project cards, an About section and contact links. Each finished card links to a short write-up in `views/`.

Built with plain HTML, CSS and JavaScript, with no build step: open `index.html` in a browser to run it.

The site started as Artifact 1 for TCSS 490 (Autumn 2026), and the five project cards are that course's artifacts. See `NOTES.md` for the development log.

## Versions

The original course version of the site (the blue AND-logo design) is kept on the `class-version` branch.

```
git switch class-version   # the original course version
git switch main            # back to the current site
```
